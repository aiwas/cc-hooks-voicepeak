# 分割結果だけ確認する

VOICEPEAK は 1 回の実行で 140 文字（日本語換算）までしか受け付けないため、
長文は字句解析して自然な位置で分割してから合成している。
このコマンドはその分割結果だけを表示する。voicepeak.exe は起動しない。

```bash
"${CLAUDE_PLUGIN_ROOT}/bin/cc-voicepeak" split $ARGUMENTS
```

`$ARGUMENTS` がテキストならそのまま、`-f <ファイル>` ならファイルを読む。
どちらも無い場合は `--stdin` で標準入力から渡す。

## 出力の読み方

```
2 ブロック / 合計 210 文字 / 上限 140 文字
 [  1]   88 文字 | 実装が完了しました。まず設定ファイルを…
 [  2]  122 文字 | voicepeak は一回の起動で百四十文字までしか…
```

1 ブロックにつき voicepeak.exe が 1 回起動する（同時起動できないので直列）。
ブロック数がそのまま合成の待ち時間に効いてくる。

`--json` を付けると機械可読な形式で出る。

## 切れ方が不自然なとき

分割位置は「上限に収まる範囲のうち、`split.min_fill`（既定 0.55 = 77 文字）を
超えた位置にある候補から、最も優先度の高いものを選ぶ」という規則で決まる。

- **区切りを自然にしたい** → `split.min_fill` を下げる（0.3 など）。
  ブロック数が増えるので合成は遅くなる
- **起動回数を減らして速くしたい** → `split.min_fill` を上げる。
  区切りは不自然になりやすい

その場で試す場合は `--min-fill` を付けて比較する。
気に入った値は設定ファイル（`.claude/voicepeak.json`）の `split.min_fill` に書く。

読み上げ用の整形（Markdown の除去や読み替え）を挟まない生の分割を見たい場合は
`--no-normalize` を付ける。
